# Skill attribution

The skills in this directory are part of this project. Four of them are adapted
from public MIT-licensed collections: the workflow was rewritten for this
pipeline's artifacts and phase boundaries, and each file names its upstream in
the `source:` frontmatter field.

| Local skill | Upstream | Owner |
|---|---|---|
| `requirements-spec` | [awesome-copilot · create-specification](https://github.com/github/awesome-copilot/blob/main/skills/create-specification/SKILL.md) | GitHub, Inc. |
| `adr` | [awesome-copilot · create-architectural-decision-record](https://github.com/github/awesome-copilot/blob/main/skills/create-architectural-decision-record/SKILL.md) | GitHub, Inc. |
| `implementation-plan` | [awesome-copilot · create-implementation-plan](https://github.com/github/awesome-copilot/blob/main/skills/create-implementation-plan/SKILL.md) | GitHub, Inc. |
| `secrets-management` | [wshobson/agents · secrets-management](https://github.com/wshobson/agents/blob/main/plugins/cicd-automation/skills/secrets-management/SKILL.md) | see upstream repository |

The remaining skills in this directory were written for this project.
