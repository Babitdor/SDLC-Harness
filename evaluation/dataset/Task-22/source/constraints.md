# Constraints Register — Broadband LEO Satellite

Document: CON-SAT-022
Revision: B

C1–C3 are stated in the requirements specification; this register continues from C4.

| ID | Constraint | Value | Notes |
|---|---|---|---|
| C4 | Wet mass | ≤ 500 kg | Includes propellant for 7-year station-keeping + de-orbit |
| C5 | Orbit-average power | ≤ 1.5 kW | Solar array sizing at end of life (EOL) with 3 %/yr degradation |
| C6 | Stowed envelope | 1.2 × 1.2 × 1.5 m | Compatible with the selected launcher's payload envelope |
| C7 | Throughput | ≥ 20 Gbps | Aggregate user + feeder link, full-duplex |
| C8 | One-way latency | ≤ 5 ms | Onboard processing + queuing + link propagation (incl. ISL) |
| C9 | Design life | ≥ 7 years | 550 km sun-synchronous orbit (SSO) |
| C10 | Eclipse duration | ≤ 35 min | Battery depth of discharge (DoD) ≤ 30 % |
| C11 | Unit recurring cost | < USD 15 M | At a production run of 100+ units |
| C12 | Timeline | 36 months | From SRR to launch readiness |
